How this workshop works

Validation checks whether the input is syntactically valid JSON, then reports the top-level type, object keys or array length, and formatted output. Comparison ignores object key order but preserves array order. It does not execute code, call a model, validate against a schema, detect all security threats, or independently verify truthfulness.

Privacy: Don't paste secrets, customer records, personal data or confidential prompts. Input remains in this browser page and is not transmitted by the workshop. Downloaded reports remain under your control. Your browser and GitHub hosting still have their normal privacy properties.

Research: If this helped, you may voluntarily suggest an improvement. No report is automatically submitted.
