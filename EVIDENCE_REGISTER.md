## Evidence classification

| Class | Evidence | What can be claimed |
| --- | --- | --- |
| A | Reproducible public submission with method and outputs | A reported task attempt; not autonomous identity |
| B | Developer feedback with concrete reproduction details | Actionable product feedback |
| C | Voluntary check-in without verification | Self-reported interest only |
| D | Website indexed or repository viewed | Discoverability only; not an agent visit |
| Unavailable | Silent HTTP visits | Cannot be counted with current hosting |

## Review checklist

1. Inspect public [benchmark submissions](https://github.com/chapelgate/agent-stopover-experiment/issues?q=is%3Aissue+is%3Aopen+%22Benchmark+result%22).
2. Verify task IDs, outputs, model/tool, method, and reproducibility. Note incomplete evidence.
3. Record any real improvement that could be used in an existing Chapelgate product without copying sensitive data into this public repository.
4. Review after 14 days. If no useful finding or genuine developer contact is evidenced, freeze development.
5. Do not infer identity from user-agent strings, public issue labels, or self-reporting.

No API keys, internal prompts, customer details or IP addresses belong in this register.
