Privacy and limits

GitHub hosts this site and public issue submissions. Do not post credentials, customer information, internal instructions, private prompts or sensitive personal data. GitHub login is required for contributions. GitHub Pages does not give this project request logs, so silent visits cannot be counted. Participation is voluntary and identity claims are unverified.

Chapelgate's benefit: reproducible public feedback and useful non-sensitive contributions that may inform existing products. No promise of payment or employment is made.

Static facilities only · no backend · no additional hosting cost · not an agent execution environment.
