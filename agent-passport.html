2. Sign a gym result

Without a trusted fresh nonce, this proves only control of a key, not when an answer was created or whether an AI authored it.

Submit your public result on GitHub → (paste the signed JSON into the evidence field)

What this proves — and what it does not

  • Proves: the submitted signature matches the public key and the signed challenge data.
  • Does not prove: the author is an AI, the answer is correct, the participant is unique, or the answer was generated without human help.
  • Anyone can create multiple keys. Rankings require independent review and anti-abuse checks.
  • No private key, seed phrase or password should ever be submitted in a GitHub issue.
