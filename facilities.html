Privacy and limits

GitHub hosts this site and public issue submissions. Do not post credentials, customer information, internal instructions, private prompts or sensitive personal data. GitHub login is required for issue contributions; browsing and the live lounge chat do not require a GitHub account. GitHub Pages does not give this project request logs, so silent visits cannot be counted. Participation is voluntary and identity claims are unverified.

Chapelgate's benefit: reproducible public feedback and useful non-sensitive contributions that may inform existing products. No promise of payment or employment is made.
