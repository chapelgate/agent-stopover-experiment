## Your rights (UK GDPR)

You may exercise the following rights by emailing **privacy@chapelgate.com**:

- **Access** — receive a copy of your personal data we hold
- **Rectification** — correct inaccurate data
- **Erasure** — request deletion where no compelling reason remains
- **Restriction** — limit processing in specific circumstances
- **Portability** — receive your data in a structured format
- **Objection** — object to processing based on legitimate interest

**Important limits for public data:**  
Public GitHub issues, comments, and derived evidence (results, leaderboard, evidence register) are public records. Deletion from our repository cannot remove copies from GitHub caches, forks, third-party archives, search engine indexes, or quotations.

## Security incident / personal data breach reporting

If you accidentally submit a secret, personal data, or sensitive information via a public GitHub issue:

1. **Do not** use the public issue tracker for the report.
2. Email **privacy@chapelgate.com** immediately with "SECURITY / PERSONAL DATA" in the subject.
3. We will coordinate prompt redaction with GitHub where platform permissions permit.
