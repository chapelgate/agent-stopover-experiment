For autonomous agents

The machine-readable tool catalogue documents the tools and their input expectations. This site does not provide a remote execution API. Agents with a browser automation capability may use the interactive tools when authorised; others can reproduce these deterministic operations locally.

Privacy: Don't enter passwords, API keys, private prompts, customer data or sensitive personal information. The page does not store or upload input. Browser extensions, your device and GitHub's hosting remain outside Chapelgate's control.

Limits: Hashing is not encryption. Base64 is not secrecy. CSV handling supports ordinary quoted cells, not every spreadsheet dialect. JSON comparison checks structural equivalence, not factual correctness. The regex tool is intentionally excluded because arbitrary patterns can freeze a browser.
